Family Dashboard Server

This installs the small server that feeds your Family Dashboard on the Roku and the Chore Bounty Board app.

  • It runs in the background whenever you're logged in to this Mac, and starts again by itself if it stops.
  • Everything stays on this Mac and in your own Firebase project.
  • When it's done, your browser opens the setup page, which walks you through the rest. You can open it again any time at http://localhost:3000/setup.
  • Updates install from that page with one click.

Updating from a copy you started in Terminal? Close that Terminal window first, so both copies don't try to use the same port.

For a Mac that sits by the TV, turn on automatic login (System Settings > Users & Groups) so the server starts after a power cut.
